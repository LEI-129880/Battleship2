# Checkstyle — nomes de métodos

## Regra escolhida

Tipo de identificador: métodos. Convenção: `lowerCamelCase`, aproximada pelo padrão `^[a-z][a-zA-Z0-9]*$` da regra `MethodName`. O nome deve começar com uma letra minúscula ASCII e continuar apenas com letras ou algarismos, sem underscores. A configuração ativa apenas esta regra de nomes, sem impor regras de indentação ou Javadoc.

## Limitações

O Checkstyle verifica a forma do identificador, mas não consegue determinar se o nome descreve corretamente o comportamento do método. O padrão também aceita nomes pouco informativos, como `x`, e não verifica a separação semântica das palavras nem proíbe todas as sequências de maiúsculas. A regra `MethodName` não verifica nomes de métodos sobrescritos identificados como tal, pois o programador pode estar obrigado a conservar o nome definido na API.
